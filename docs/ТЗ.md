# Техническое задание (ТЗ)
## на разработку информационной системы "Candy Delivery"

### 1. Введение
**1.1. Наименование системы:** Информационная система управления доставкой кондитерских изделий "Candy Delivery".

**1.2. Цель создания:** Автоматизация процессов найма курьеров, приема заказов и оптимального распределения заказов между курьерами с расчетом их рейтинга и заработка.

**1.3. Состав команды:** 2 человека.
- Участник 1: Разработка Backend (REST API, БД, логика распределения, тестирование).
- Участник 2: Разработка Frontend (Веб-интерфейс на React, интеграция с API).

### 2. Требования к системе
**2.1. Функциональные требования:**
- **Авторизация:** Вход в систему по логину и паролю с выдачей JWT-токена. Разделение ролей: `admin` и `courier`.
- **Управление курьерами (Admin):** Массовый импорт данных курьеров (ID, тип, регионы, часы работы), просмотр списка, редактирование данных. Автоматическое создание учетной записи курьера при импорте.
- **Управление заказами (Admin):** Массовый импорт заказов (ID, вес, регион, интервалы доставки).
- **Распределение заказов (Система/Courier):** Автоматический подбор максимального количества подходящих заказов для курьера с учетом:
  - Грузоподъемности (пеший: 10 кг, вело: 15 кг, авто: 50 кг).
  - Совпадения региона доставки и региона работы курьера.
  - Пересечения графиков работы курьера и интервалов доставки заказа.
- **Выполнение заказов (Courier):** Отметка о выполнении заказа с фиксацией времени.
- **Статистика (Система):** Автоматический расчет рейтинга курьера (на основе среднего времени доставки по районам) и суммы заработка (с учетом коэффициента типа курьера).

**2.2. Нефункциональные требования:**
- Архитектура: RESTful API, соответствующая спецификации OpenAPI.
- Валидация всех входящих данных на уровне схем Pydantic.
- Хранение данных: реляционная СУБД PostgreSQL.
- Безопасность: Хэширование паролей (или безопасное хранение), защита эндпоинтов через JWT Bearer Token.
- Кросс-доменные запросы (CORS) должны быть настроены для взаимодействия с Frontend-приложением.

### 3. Стек технологий
- **Backend:** Python 3.10+, FastAPI, SQLAlchemy (ORM), Pydantic, PyJWT, psycopg2-binary.
- **База данных:** PostgreSQL.
- **Frontend:** HTML5, React (Vite), JavaScript (ES6+), CSS3, Fetch API.
- **Тестирование:** pytest, requests.
- **Управление версиями:** Git, GitHub.

### 4. Документация API
Полная спецификация API описана в формате OpenAPI в файле `docs/openapi.yaml`. 
Интерактивная документация также доступна по адресу: `http://127.0.0.1:8000/docs` после запуска сервера.
