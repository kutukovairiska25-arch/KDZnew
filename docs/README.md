Информационная система управления доставкой кондитерских изделий.

## Архитектура и структура проекта

Проект построен по принципу разделения ответственности (Separation of Concerns). Ниже приведено описание ключевых модулей.

### Backend (Серверная часть)
- **`main.py`** — Главная точка входа. Инициализирует FastAPI, настраивает CORS и подключает роутеры.
- **`config.py`** и **`database.py`** — Управление переменными окружения (.env) и конфигурация подключения к PostgreSQL через SQLAlchemy.
- **`models.py`** — ORM-модели, описывающие структуру таблиц базы данных (`User`, `Courier`, `Order`).
- **`schemas.py`** — Схемы валидации Pydantic для входящих JSON-запросов и исходящих ответов.
- **`crud.py`** — Слой доступа к данным. Содержит функции Create, Read, Update, Delete, изолируя работу с БД от роутеров.
- **`utils.py`** — Чистая бизнес-логика: расчет рейтинга, подсчет заработка и проверка пересечения временных интервалов.
- **`auth.py`**, **`couriers.py`**, **`orders.py`** — Роутеры (маршрутизаторы), описывающие HTTP-эндпоинты API.
- **`createDbUsers.py`** — Скрипт для инициализации тестовой базы данных и создания пользователей по умолчанию.

### Frontend (Клиентская часть)
- **`main.jsx`** — Точка входа React-приложения, рендеринг корневого компонента.
- **`App.jsx`** — Настройка маршрутизации (React Router) и перенаправление пользователей в зависимости от их роли.
- **`api.js`** — Единый централизованный слой для HTTP-запросов. Автоматически добавляет JWT-токен в заголовки и обрабатывает глобальные ошибки (например, истечение сессии).
- **`pages/`** (`Login.jsx`, `AdminDashboard.jsx`, `CourierDashboard.jsx`) — Страничные компоненты, содержащие основную бизнес-логику интерфейса и управление состоянием (useState, useEffect).
- **`components/`** (`Sidebar.jsx`) — Переиспользуемые UI-элементы, вынесенные в отдельные файлы для чистоты кода.
- **`*.css`** — Файлы стилей, реализующие дизайн-систему Glassmorphism и адаптивную верстку.

## Функционал системы

### Роль "Администратор"
- Авторизация в системе.
- Массовый импорт данных курьеров и заказов через JSON с валидацией на стороне клиента и сервера.
- Просмотр полных списков курьеров и заказов.
- Редактирование данных курьера (тип транспорта, регионы, часы работы) с автоматическим сбросом неактуальных назначенных заказов.
- Отмена назначенного заказа и полное удаление заказа из системы.

### Роль "Курьер"
- Авторизация и просмотр личного профиля с динамически рассчитываемыми метриками (рейтинг, заработок).
- Запрос на получение новых заказов (система автоматически подбирает заказы с учетом грузоподъемности, совпадения регионов и пересечения графиков работы).
- Отметка о выполнении заказа с фиксацией времени.
- Просмотр персональной статистики выполненных и отмененных заказов.

### Системная бизнес-логика
- **Распределение:** Учет грузоподъемности (пеший: 10 кг, вело: 15 кг, авто: 50 кг).
- **Расчет рейтинга:** На основе среднего времени доставки по районам.
- **Расчет заработка:** Фиксация типа курьера на момент назначения заказа для честного расчета коэффициента оплаты, даже если тип курьера был изменен администратором позже.
