# Candy Delivery System

Информационная система управления доставкой кондитерских изделий. 
Проект разработан в рамках курсового домашнего задания (КДЗ) по дисциплине "Технологии и методы программирования".

## Состав команды
- **Backend-разработчик:** Кутукова Ирина — проектирование API, работа с БД, тестирование.
- **Frontend-разработчик:** Галиуллина Руслана — проектирование UI, интеграция с API.

## Стек технологий
- **Backend:** Python 3.13, FastAPI, SQLAlchemy, Pydantic, PyJWT, PostgreSQL.
- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Fetch API (без использования фреймворков).
- **Тестирование:** pytest, requests.
- **Управление версиями:** Git, GitHub.

## Функционал системы
- **Администратор:** Авторизация, импорт курьеров и заказов, просмотр и редактирование данных курьеров.
- **Курьер:** Авторизация, просмотр профиля, получение заказов, отметка о выполнении заказов, просмотр истории.
- **Бизнес-логика:** Автоматическое распределение заказов с учетом грузоподъемности, регионов и графиков работы. Расчет рейтинга и заработка курьеров.
